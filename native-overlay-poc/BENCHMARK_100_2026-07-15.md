# Native overlay — 100-toggle benchmark

**Run:** 2026-07-15, local desktop compositor  
**Command:** `cargo run --release -- --benchmark 100`  
**Surface:** dependency-free Win32 topmost, translucent, click-through,
no-activation proof. Every sample calls `DwmFlush` after show/hide.

| Metric | Result |
|---|---:|
| Show average | 19.86 ms |
| Show p95 | 31.36 ms |
| Show maximum | 32.25 ms |
| Hide average | 20.90 ms |
| Hide p95 | 31.15 ms |
| Hide maximum | 46.74 ms |

## Decision

The window mechanics are repeatable over 100 toggles and remain within two
60 Hz frames at p95. Continue the native experiment for **borderless/windowed**
apps and games only. This is not yet permission to replace the prewarmed Tauri
Quick Menu: the proof does not render equivalent liquid glass, does not bridge
controller input, and has not been benchmarked against Tauri under equal work.

The GDI/USER readings remain diagnostic telemetry, not a leak verdict; the
next test must create/destroy a window repeatedly and compare memory/handles
against an equivalent Tauri workload. Exclusive fullscreen Fortnite is outside
the supported overlay model.
