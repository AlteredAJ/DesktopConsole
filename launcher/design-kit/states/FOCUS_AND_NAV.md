# Focus and navigation reference

## Regions

1. `quick` — Wi-Fi, Sound, Settings. D-pad down returns to dock.
2. `tabs` — L1/R1 move Apps / Games / Launchers.
3. `dock` — D-pad and touchpad move exactly one focused tile.
4. `panel` — Circle closes the current panel; panel focus stays inside it.

## Tile states

- Default: slightly shadowed raised icon surface, subdued label.
- Focused: lift upward, white specular rim, soft content-colour bloom, bright label.
- Running: one small neutral-white dot below the tile; no extra badge system.

## Shelf requirements

The Games shelf deliberately exceeds the viewport. Centre the focused tile when
possible; at the end of the shelf retain a comfortable crop, never shrink tile
targets. Long labels (`The Alto Collection`, `Assetto Corsa`, `BeamNG.drive`)
are single-line ellipsis labels.
